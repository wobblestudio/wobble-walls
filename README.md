## About the Game

**Wobble Walls** is a pure client-side tower defense game set in a neon cyber-fantasy world.  
Defend the kingdom by placing powerful towers, surviving endless waves, and defeating powerful bosses.

- 10 unique towers with different elements
- Unlimited waves with progressive difficulty
- Boss every 5 waves
- Upgrade & Sell system
- Username + local progress saving
- 3 different maps
- Background music + sound effects
- Fully playable on mobile & desktop

## How to Play

1. Enter your username
2. Choose a map
3. Place towers on the available spots
4. Survive as many waves as possible
5. Upgrade or sell towers strategically
6. Defeat the Boss every 5 waves

**Controls:**
- Tap / Click to place towers
- Tap existing tower to Upgrade or Sell
- Use `1X / 2X / 3X` for game speed
- Pause and Mute buttons available
